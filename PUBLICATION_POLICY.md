# Public Publication Policy / Правила публичных публикаций

This repository exists for verified product information, updates and public-facing documentation only.

**Do not publish:** active development source code; source archives or build scripts; cryptographic secrets or identity stores; full debug logs; internal security reports; device identifiers; private IP/network maps; unreleased GNP/1 wire-level details; personal information; internal development or release automation.

**Permitted after review:** product overview; verified feature summaries with accurate status; scrubbed demonstrations and screenshots; public release notes; contact and legal information reviewed for privacy.

Every publication must be reviewed before it is pushed to a **public** repository. A private repository is not a substitute for a protected secret store.

---

Этот репозиторий предназначен только для проверенной информации о продукте и публичной документации.

**Не публиковать:** исходники активной разработки; архивы кода и скрипты сборки; криптографические секреты и хранилища идентичностей; полные диагностические журналы; внутренние отчёты безопасности; идентификаторы устройств; сетевые карты; неопубликованные подробности формата GNP/1; личные данные; внутренние средства выпуска.

**Допустимо после проверки:** описание продукта; подтверждённые возможности с корректным статусом; обезличенные демонстрации; публичные заметки о версиях; проверенные контактные и правовые сведения.

Любая публикация проверяется **до** отправки в публичный GitHub.
