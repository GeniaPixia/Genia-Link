Genia Link is an independently developed, local-first device connectivity project for **Windows and Android**, powered by the **GNP/1** protocol.

It aims to let trusted devices discover each other on the local network and use device services without a mandatory cloud account or Internet relay.

## What is currently validated?

| Capability | Status |
| --- | --- |
| Trusted local device discovery, pairing and file exchange | Tested in development |
| Encrypted authenticated sessions and file integrity | Implemented and tested in development |
| Remote printing through a trusted Windows device | Physically validated in selected development scenarios |
| Remote single-page scanning from Android through a trusted Windows scanner gateway | Physically validated in selected development scenarios |
| Unified Windows/Android interface and RU/EN localization | Work in progress |

Validation of selected scenarios does not imply a full public release, certification, universal device compatibility or independent security audit.

## Availability

**This is the official public project information repository.** It contains product-facing documentation and public updates, **not** the full source tree or production signing material. The project is under active development. No EXE or APK distribution is currently offered here.

## Development principles

- Local-first network services and explicit device trust.
- Cryptographic authentication for sensitive operations.
- Privacy-first handling of files and device identity.
- Compatibility and safety checks before expanding supported capabilities.
