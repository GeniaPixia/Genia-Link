# Security Policy / Политика безопасности

## English

Genia Link is under active development. Please do not post exploit details, credentials, private cryptographic material, real device identifiers, personal files or sensitive logs in public issues.

If GitHub private vulnerability reporting is enabled for this repository, please use it. Otherwise, open only a minimal issue requesting a private reporting channel; do not attach exploit or credential data. Public issues do not create a confidential communication channel.

The project has not undergone an independent external cryptographic security audit. Local-first does not mean vulnerability-free.

## Русский

Genia Link находится в разработке. Не размещайте в публичных Issues подробности эксплуатации уязвимостей, пароли, токены, приватные ключи, реальные идентификаторы устройств, личные файлы и конфиденциальные журналы.

Если в репозитории доступно приватное сообщение об уязвимости, используйте его. Иначе создайте только краткое публичное обращение с просьбой предоставить закрытый канал связи — без технических подробностей и секретов.

Независимый внешний криптографический аудит проекта пока не проводился.
